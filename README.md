# Dissertation Intelligence

A browser-based research workspace for organising a dissertation about whether coaching qualifications are necessary in sport.

## Features
- Literature library for recording sources and reference details
- Evidence matrix for methods, findings, relevance and limitations
- Research question studio
- Searchable research notes
- Dissertation task planner
- JSON backup and restore

## Run locally
Open `index.html` in a modern web browser. No installation or server is required.

## Data and privacy
Entries are saved in the browser's local storage on the device being used. They are not automatically uploaded to GitHub or synchronised between devices. Use **Data & settings → Export backup** to keep a copy.

## Research reminder
This tool organises research; it does not verify sources or replace critical reading. Check every source and reference against the original publication, and discuss your final research question and methods with your supervisor.
